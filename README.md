# Hexlet-git

Проект, разработанный в рамках обучения. Содержит структуру с изолированной логикой в папке `src` и подключенным линтером ESLint. Также подключена библиотека Lodash.

## Команды автоматизации

Для удобства разработки в проекте настроен `Makefile`. Вы можете использовать следующие команды в терминале:

- `make install` — выполняет чистую установку всех зависимостей проекта (`npm ci`) строго по файлу конфигурации lock.
- `make lint` — запускает полную проверку исходного кода на соответствие правилам линтинга (ошибки, неиспользуемые переменные и синтаксис).
- `make lint-fix` — автоматически исправляет большинство мелких стилистических ошибок в коде.
